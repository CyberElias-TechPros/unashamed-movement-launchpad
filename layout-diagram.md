## Mermaid Diagram

```mermaid
graph TD
    A[Navbar<br/>Logo + Nav Links + CTA] --> B[Hero Section<br/>Full-width Image + Text]
    B --> C[Join Section<br/>Title + Ticket Preview]
    C --> D[Lineup Section<br/>Artist Cards Slider]
    D --> E[Impact Section<br/>Stats: 100+ / 30K / 15+]
    E --> F[Rundown Section<br/>Schedule Timeline]
    F --> G[Event Section<br/>Feature Cards]
    G --> H[Pricing Section<br/>$199 Festival Pass]
    H --> I[Testimonials Section<br/>Review Slider]
    I --> J[CTA Section<br/>Call to Action]
    J --> K[Footer<br/>Links + Newsletter]

    subgraph SectionTypes
    C -.- C1[TAG + Heading + Description]
    D -.- D1[TAG + Heading + Card Grid]
    E -.- E1[TAG + Heading + Stats]
    F -.- F1[TAG + Heading + Timeline]
    G -.- G1[TAG + Heading + Icon Cards]
    H -.- H1[TAG + Heading + Pricing Card]
    I -.- I1[TAG + Heading + Slider]
    J -.- J1[TAG + Heading + Button]
    end
```

## Design System Summary

| Element | Value |
|---------|-------|
| **Primary Colors** | Dark theme with orange accents |
| **Typography** | Geist (Headings), Geist Mono, Inter (Body) |
| **Animations** | Text glitch effect ("hack-text"), pixel reveal on images |
| **Sections** | 11 main sections |
| **Interactive** | Carousel sliders, newsletter form, navigation |
| **Responsive** | Mobile, tablet, desktop breakpoints |
